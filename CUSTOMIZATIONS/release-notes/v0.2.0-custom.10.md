# v0.2.0-custom.10

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动

> 本版本覆盖 `CUSTOM-20261008-202` … `CUSTOM-20261009-209`（custom.9 之后的全部轮次）。

### 会话恢复（新功能）

- `20261009-209`：**重载/关闭编辑器后再打开面板，会问一句「要不要恢复上次开着的几个会话 tab」**（参考浏览器的标签页恢复）。选【Restore】后 tab **按原顺序立刻回来**，只有上次聚焦的那条真加载、其余**点开才加载**（大会话的 replay 是秒级到十几秒，逐个 eager 恢复要等一两分钟）；选【Start fresh】就保持原来的行为（直接开一个新会话）。卡片上还有「Remember my choice」—— 勾了再选，就记成"以后总是恢复"或"以后别再问"（也可以在设置里改 `acpc.restoreSessionsOnOpen`：`ask` / `always` / `never`）。

### 卡顿：「loading 期间点 tab 没反应」

- `20261008-202`：用户报「在 New Session 打开历史会话时，loading 的过程中没法切换到其他会话 tab」。真机日志给出三条判据 —— 客户端**连续 50 秒一行日志都没有**、恢复后的**第一刻**打出来的正是那次点击、紧接着是攒了一路的一批 markdown 回填**一次性涌出** —— 也就是**主线程被一个长任务占住、输入被浏览器压后**（不是焦点或守卫的问题；同一份转录在宿主侧渲染只要 0.6 秒，卡的不是宿主）。现在：回填应用按 ≤8ms **时间片**落地（一个批次不再落在一个任务里），`scroll.follow()` 里那次"只为诊断"的几何读改成只在真会记下来时才读，并新增一个**常驻的长任务看门狗** —— 下次再"点了没反应"，日志里会直接有 `[acpc] longtask NNNNms during=<哪一段>`。

### 面板里的文件引用

- `20261008-205`：修「IDE 注入的"当前打开的文件"被当成了第二个气泡」—— `<ide_opened_file>…</ide_opened_file>` 是 **IDE 注入的上下文**、不是用户说过的话；现在不建记录，抠出的路径变成**这条消息上的文件 chip**（与官方插件同款：chip 在上、正文在下）。
- `20261008-206` / `207`：气泡里的文件 tag 与折叠三角**同一行**（原来掉在第二行）、tag 加高、文件名前带 `</>` 图标；**输入框的引用栏新增「编辑器当前文件」格** —— `+` 加进本条消息的引用（变成 `×`）、自动带**选中行区间**（`foo.cs:12-40`，agent 也看得到），点 tag 本体直接打开那个文件。
- `20261008-207` / `208`：**同一个文件可以引用多段**（框选的行与已引用的不同 ⇒ 还能再引用一次；相同 ⇒ 显示 `×`，点它只摘这一段）；那一格收成**一整格 chip**（开关在里面），两态用底色 + 描边区分（预选 = 带强调色 + 虚线，已引用 = 与其它附件 chip 一致 + 实线）。

### 侧栏与目录

- `20261008-204`：修「点一下地址栏的 `Times`，右侧大纲栏自己打开了」+「关掉右侧栏、重启编辑器后又开着」—— 同一个根因：偏好里混了"此刻是否可见"，而偏好回话是**广播**的（点 `Times`、拖 tab、拖大纲宽度都会写一次偏好 ⇒ 把刚关掉的侧栏弹回来）。现在侧栏的开/关**按会话记**（与 `Times` 同一套语义）且关闭一律落盘。
- `20261008-203`：修「刚通过 Browse 选择的目录不进 Recently used」—— 宿主那侧没问题（`session/new` 的 cwd 就是它），是客户端把目录候选**一次拉取、终身缓存**了；现在每次打开抽屉都回头问一次（先渲染手上那份，回复到了就地刷新）。

### 更早一轮（custom.9 之后的 199-201 已在本版前的提交里，此处一并列出）

- `199`：已连接但还没有会话时（首次连接要下载适配器的那几十秒）地址栏显示默认目录、`Times` 等右侧控件不再滑到左边。
- `200`：`Times` 开关**按会话记**（+ 一个"最后一次拨动"的默认值），状态从 webview 本地搬进宿主 globalState，重载后仍记得。
- `201`：tab 拖拽的落点在**整条标签栏**上（末尾空白与缝隙过去没有落点 ⇒ 松手就复位），并留下 `tabdrag` 诊断日志。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.10.vsix`，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.10.vsix
```
