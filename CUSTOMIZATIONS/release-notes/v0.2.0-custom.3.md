# v0.2.0-custom.3

基于上游 [formulahendry/vscode-acp](https://github.com/formulahendry/vscode-acp) `0.2.0`（commit `e7371659`）。

## 这个版本做了什么

在 custom.2（Chat 面板重写）的基础上，补齐了编辑区面板、面板内权限/历史/大纲等能力，
并对对话区与记录区做了一轮系统性打磨与修复。主要变化：

| 能力 | custom.2 | 本版本 |
|---|---|---|
| 编辑区标签页 | 仅侧边栏 | **可在编辑区打开同一会话**（`ACP (Custom): Open Chat in Editor Area`，`ctrl+alt+a`） |
| 权限请求 | QuickPick 弹框 | **面板内权限卡片**（并发请求排队、取消轮次自动回答） |
| 会话大纲 | 无 | **☰ 大纲抽屉 + 可钉住的常驻右侧栏**（user+assistant、类型图标、可调宽） |
| 历史会话 | 依赖侧边栏 | **面板内 ↺ 历史选择器**（含每会话目录显示、标题兜底） |
| 新建会话 | 立即建会话 | **草稿页**：先选目录、首次发送才建会话（不再产生空会话） |
| 会话目录 | 全局一个 | **每会话一个工作目录**（按会话级 cwd 拉起） |
| 工具输出 | 纯文本 | **按 markdown 渲染**（代码块 / 表格 / Copy） |
| 消息折叠 | 无 | 用户消息 / 思考块按实测行数折叠 |
| 时间信息 | 不显示 | hover 完整时刻、工具耗时、Times 开关 |
| 右键菜单 | 系统原生 | **自定义菜单**（Copy message / Copy code / Select all） |
| 会话改名 | 无提示 | 自动标题只做基线，改名留一条提示 |
| 回归测试 | 28 条 | **58 条**（含客户端逻辑的常驻桩 DOM 测试） |

### 面板内三入口（不再依赖侧边栏）

- **Connect Claude Code**：空态一键拉起进程（有会话则聚焦最新，无则不建空会话）。
- **↺ 历史会话**：标题栏拉出该 agent 的历史列表，点一条即 `session/load` 重放（退化为 resume）。
- **草稿页**：点 `+` 开本地草稿，选目录后首次发送才真正建会话。

### 记录区（061–075）与大纲侧栏（076/077）

对话区与记录区按用户 F5 复验的反馈做了多轮打磨：空白条、工具卡空壳、plan 卡永不更新、
GFM 任务列表、折叠判据、时间显示、右键菜单、引导条对齐等（详见 change-id 一览）。

## ⚠️ 与上游并存的注意事项

本扩展**可以与上游 `formulahendry.acp-client` 同时安装**。设置项键名不同（`acpc.*`），
命令统一带 `ACP (Custom): ` 前缀。从上游迁移需把 settings.json 的 `acp.*` 改成 `acpc.*`。

## 已知问题

- **子 agent 分组是推断的**（ACP 协议无此概念，带 `?` 角标为时序推断，会话头部可切回扁平列表）。
- **旧面板（非 Claude Code agent）继承上游缺陷未修**：文件附件不可用、Escape 取消失效、
  工具调用不显示详情——刻意不在上游文件里修，避免制造合并冲突。
- 切换 agent 时聊天面板会整体重渲染（记录不丢，滚动位置重置）。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.3.vsix`，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.3.vsix
```

或在 VS Code 中：扩展面板 → `...` 菜单 → **Install from VSIX...**
