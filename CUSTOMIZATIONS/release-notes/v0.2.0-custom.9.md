# v0.2.0-custom.9

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动

> 本版本覆盖 `CUSTOM-20261005-192`（滚动诊断的第二版：手势落点 `press@…` + `sf=`）之后的全部轮次：
> 193、194、195、197、198、199、200、201。

### 草稿页与连接体验

- `20261005-193`：**草稿页（New Session）也能粘贴 / 拖入图片与文件**。附件通道此前全是会话作用域的，而草稿页按定义还没有会话 ⇒ 一律报 "no session is focused"。现在草稿页先在本地攒着（按 draftId 记，只在内存），首条消息建完会话后由宿主**按原路**落账（不另存一份），发送路径一字未改。
- `20261006-194`：**连接卡住时卡片说得出"为什么"**。此前连不上只有一句 `Connecting…`，而真原因（npx 正在下载新版适配器：`will be installed: …`）只进日志——`agent-stderr` 事件此前**零订阅者**。现在连接相位把 agent stderr 显示在卡片上，并给按钮加一个秒表：数字在动就说明"还在等"，而不是"死了"。
- `20261006-195`：**草稿页「首条消息 → 会话就绪」之间显示 `Creating this session…`**（转圈 + 秒表）。真机采样：这一发 `session/new` 里 `sdk-initialize` 一步有时 675ms、有时 13 秒，而这段时间界面上**没有任何一处**能看出"已经在建了"（输入框里的字又故意留着）。顺带修掉 194 那个**一次都没显示过数字**的秒表（`connectStartedAt` 写在 `stopTick()` 之前，被当场清零）。

### 标签栏

- `20261007-197`：**置顶悬浮卡上也能「Copy message」**。右键菜单此前只认记录节点，而卡片是另一棵树（`.sticky-card > .sticky-body > 克隆体`），用户右键常点的又是那一圈留白 ⇒ 菜单里除了灰着的 `Copy` 什么都没有。
- `20261007-198`：**会话 tab 支持按住左键拖拽排序**。落点按指针在目标 tab 水平中点的哪一侧算、边缘画一条 2px 指示线；顺序与大纲偏好存在**同一条** globalState 记录里（另一个面板、下次重开面板看到同一条）。宿主 `setUiPref` 因此由"重建"改为**合并**（缺的字段 = 这一轮没改它，否则拖一下 tab 会把大纲宽度重置）。
- `20261008-201`：**修"拖了但松手弹回原位"**。198 的落点只长在 tab 元素上，而 `.tabs` 是 `flex: 0 0 auto` ⇒ 最后一个 tab 右边的空白属于标签栏容器、tab 之间还有 2px 缝隙，指针落在这些地方**根本没有落点**（而这两种正是最自然的拖法）；指示线又没有 `dragleave` 清除 ⇒ 画面上"有落点"、实际没有，失败完全静默。现在**整条标签栏都是落点**（插入位按指针横坐标算），并在日志里留下 `[acpc] tabdrag start= / drop from=… to=…` 两行，便于下次一眼定位。

### 地址栏与记录时刻

- `20261008-199`：**修"新连接后地址栏空白、Times 被挤到左边"**。已连接但还没有会话时（首次连接要下载适配器，实测那 20 多秒正是这个状态）地址栏此前**整格隐藏**，而它是这一行**唯一的弹性项** ⇒ `Times` / `Sub-agents` / `☰` 那一组整组滑到左边。现在地址栏显示默认工作目录（淡一点、**点不动**，tooltip 说明"下次会话将在此目录创建"），右侧那一组固定贴右。
- `20261008-200`：**「Times」开关按会话记住**，并有一个"最后一次拨动"的默认值 —— 新会话与草稿页跟随它。状态从 webview 本地（关掉编辑器面板就没了）搬进宿主 globalState，重载窗口后仍然记得，两个面板看到同一份。切换会话时显示的是**那个会话**的选择。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.9.vsix`，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.9.vsix
```
