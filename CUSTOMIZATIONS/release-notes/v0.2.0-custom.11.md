# v0.2.0-custom.11

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动（2026-10-09 · CUSTOM-20261009-210..215）

- **210　滚动「触底却没到底」修复（第三次复发）**：
  - 底部留白改为**按结果自愈**：贴底且**真在滚动范围末尾**（`st ≥ max−1`）时，比较"末条记录底边 vs 输入卡顶边"，被压住就让唯一写者重测重写（ResizeObserver 在文档不渲染的时段会哑火）；
  - 可见性 / 尺寸变化时重判 pin 状态（日志里抓到过 `pin=1` 卡死五分钟）；
  - 日志超限从"截断清零"改为**轮转**（保留 `.log.1`）——清零恰好会毁掉要排查的那段现场。
- **211　会话 tab 右键菜单**：`Close`（同 ×）与 `Rename`（原生输入框改名，tab 与历史列表同步换名）。
- **212　历史记录弹出列表**：
  - 会话行**悬停**显示 `Archive` / `Rename` 图标按钮；归档后该条从列表消失；改名为本地覆盖；
  - 目录名改为会话名后的 `(目录名)` 后缀、靠左显示（原来被悬停图标压住）；
  - 右键菜单补齐四个上下文格：大纲行 Copy 正文 / 地址栏 Copy 目录 / 会话 tab / 历史行。
- **213　用户消息气泡**：折叠切换区收窄为**标题行 / 折叠态整行**——正文可正常框选；展开态**第一行**同样可选中（原来被 `user-select: none` 按住）。
- **214　文件引用 tag**：已引用的不再重复显示预选格（原来出现两条一样的 tag）；附件 chip 补 `</>` 图标；附件 `×` 按"路径 + 区间"只摘一段。
- **215　引用文件进气泡**：引用文件的消息发送后，用户消息卡片里能看到引用的文件 chip（点击打开该文件）——此前只进了发给 agent 的请求、气泡里没有视图。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.11.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.11.vsix
```
