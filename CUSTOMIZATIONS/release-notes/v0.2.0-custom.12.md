# v0.2.0-custom.12

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动（2026-10-09~10 · CUSTOM-20261009-216..227 / 20261010-228..229）

- **216　回放里的文件引用**：引用了文件的消息，重开会话后不再变成一串 `[@名](file:///…)` 原文——按 messageId 从 agent 转录里取回文件引用，与图片、IDE 上下文 chip 一起并回同一条气泡；只引用文件、不打字的"附件-only"消息也不会在重开后整条消失。
- **217　Thought 展开上限**：300px → 600px，长推理一次能看到更多。
- **218~220　工具输出按 markdown 渲染**：Bash/工具输出的 stdout 若是一段被围栏包起来的 GFM 表格，拆掉围栏按真表格渲染（不再是字面竖线）；拿到 markdown 的工具正文补 `.md` 类与表格换行规则。
- **219　子 agent 产出标识**：委派给子 agent（如 `story_editor`）的调用，卡片头部加一枚"subagent"chip——折叠态也看得见"这话是谁写的"，其余细节（id/模型/token/耗时/指令摘要）在 tooltip。
- **221　工具卡 OUT 上限 + 耗时**：OUT 上限 340px → 510px；耗时优先显示**工具自报**的 `elapsedTimeSeconds`。
- **223　Edit/Write 卡 diff 默认展开**：外层卡片折叠时，里面的 diff 不再也要点两次才看到。
- **224　上下文圆环 tooltip 显示 thinking token**：有就显示、没有不显示。
- **225~227　会话 tab 目录标识**：状态圆点改造成 16px 方形，写**目录缩写**（取最底层目录名，如 `story-myriad-pavilion` → `SMP`），4 字母 2×2 两行；状态色只给背景、文字固定对比色（完成态也看得见）。
- **228　修触底自愈死循环**：矮视口（输入卡几乎占满视图区）里"尾巴被盖"判据恒真、自愈又改不了任何东西，会空转刷屏——现在只有**变量真的失真**（实高比变量高出 ≥2px）才重测。
- **229　修「拉不到底」**：渲染 Edit/Write/Delete/Move 卡的 diff 时抛 `ReferenceError: tool is not defined`、渲染循环当场断掉、后面条目全不显示——补上漏传的 `tool` 参数。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.12.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.12.vsix
```
