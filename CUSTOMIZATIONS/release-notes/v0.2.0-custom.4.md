# v0.2.0-custom.4

基于上游 [formulahendry/vscode-acp](https://github.com/formulahendry/vscode-acp) `0.2.0`（commit `e7371659`）。

## 这个版本做了什么

在 custom.3 的基础上，重点做了三件事：**工具卡对齐官方插件**、**记录区折叠与排版收口**、
**AskUserQuestion 能弹面板了**。外加一套"自查工具"（真 Chromium 无头截图 + 真 agent 协议探针），
以及 35 项修复与打磨。

| 能力 | custom.3 | 本版本 |
|---|---|---|
| 工具卡标题 | 命令行（与正文重复） | **agent 写的一句话**（`rawInput.description`），命令行回到 IN 段 |
| 工具输出 | 展开后只有命令行，**输出一直空白** | **IN / OUT 两栏**（对齐官方插件），输出稳定显示；长输出限高滚动 |
| AskUserQuestion | 只有一个卡住的工具卡 | **面板内选项表单**（单选/多选/文本 + Other），可直接回答并继续 |
| 记录区折叠 | 仅多行用户消息 | **每条用户消息**都给折叠控件；**助手消息也能折叠**（折叠态一行） |
| 图片 | 独立 chip 行 | 进用户气泡（第一行，caret 之后） |
| 注入块 | 被渲染成用户气泡 | 前缀识别分流为 `meta` 提示条（不再冒充用户发言） |
| 自查 | 只有桩 DOM 逻辑测试 | **真 Chromium 无头截图 + `#probe` 几何量测**（布局类问题可自证） |
| 回归测试 | 133 条 | **167 条** |

### 工具卡（117–122）

- **标题**取 agent 写的 `description`（真抓包夹具里 4 张 Bash 卡都带），没有就回退 ACP `title`。
  它**比首帧晚到**且 `_meta` 是整体替换，所以在 store 里 latch——否则真机上标题会闪回命令行。
- **IN / OUT 两栏**：段标在左列、内容在右列（一张卡省掉两行）；工具输出的字体与命令**统一成编辑器字体**，
  左边界逐像素对齐（实测两侧正文同起于 x=71）。
- **"OUT 空白"的三重根因**全部修掉：①工具正文的 markdown 请求**从来没人发**（队列只写不读）；
  ②请求里的工具项**漏了必填的 `sessionId`**，被宿主逐项校验时静默丢弃；③空白文本项与 `rawOutput` 兜底。

### AskUserQuestion 表单（119）

ACP 里它走 **elicitation（form 模式）**，而 agent 用 `clientCapabilities.elicitation.form` 门控——
不声明时**连工具本身都被禁用**。本版本声明该能力并实现 `unstable_createElicitation`：
桥（与权限卡同构：FIFO / 恰好回答一次 / 取消与会话关闭时兜底）→ 面板表单卡
（Submit / Skip / Cancel，三态与 ACP 语义一一对应）。MCP elicitation 与"拒绝回退确认"共用同一套实现。

> **已知边界**：重开一个**由别的客户端发起**且停在提问上的会话时，面板不会弹表单——
> agent 在 `session/load` 时只回放工具卡、不会重抛提问（那个未决请求在另一个进程里）。
> 详见 `CUSTOMIZATIONS/docs/pitfalls.md` #32。

### 自查工具（116）

- `CUSTOMIZATIONS/scripts/preview-records.mjs`：把 webview 真正用的 CSS / 标记 / 客户端模块拼成独立
  HTML，用本机 Chrome 无头截图（`#expanded` / `#collapsed` / `#tools`），**记录区的布局问题在 F5 之前就能看到**；
  新增 `#probe` 模式输出实测几何，供"对齐/间距"这类问题定坐标。
- `CUSTOMIZATIONS/scripts/probe-elicitation.mjs`：用真 agent 验证表单协议（收到、解析、回答、agent 收下）。
- 新增真抓包夹具 `src/test/fixtures/claude-code-bash-tools.json`（Bash 工具载荷的真实形状）。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` **同时安装、独立配置**。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.4.vsix`，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.4.vsix
```
