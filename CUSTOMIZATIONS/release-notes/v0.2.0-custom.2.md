# v0.2.0-custom.2

基于上游 [formulahendry/vscode-acp](https://github.com/formulahendry/vscode-acp) `0.2.0`（commit `e7371659`）。

## 这个版本做了什么

**Chat 面板重写。** 上游的聊天面板是单文件 87KB、单会话、单 agent 的实现；本版本把它拆成
`src/ui/chat/` 下一个可维护的子系统（28 个模块），并顺带补上了上游一直没有的能力。

### 主要变化

| 能力 | 上游 / custom.1 | 本版本 |
|---|---|---|
| 同时连接的 agent | 1 个 | **多个（各自独立进程并行）** |
| 同一 agent 的会话 | 1 个 | **多个（标签页切换，各自保留记录）** |
| 工具调用详情 | 无 | **行级 diff / 终端输出 / 文件跳转** |
| 文件附件 | 不可用（端到端断路） | **可用**（以 `resource_link` 发送） |
| 思考过程 | 显示但永不收束 | **自动收束并显示耗时** |
| 子 agent | 不显示 | **缩进分组**（见下方"关于推断"） |
| markdown | 无消毒 | 转义 + 允许列表双重防护 |
| 撤销当前轮次 | Escape 失效 | 输入框内 Escape / ■ Stop 按钮 |

### 面板路由

新面板**目前只对 Claude Code 生效**（按 `acpc.agents` 的配置键匹配）。
其余 agent 仍走原面板，行为与 custom.1 一致——包括它原有的缺陷（见"已知问题"）。

判断当前是哪块面板：**有标签行 + `+` 按钮的是新面板**，没有的是旧面板。

### ⚠️ 关于子 agent 分组：这是推断，不是协议事实

**ACP 协议里没有"子 agent"这个概念**——工具调用是扁平的，只以 `toolCallId` 为键。
本版本显示的父子关系是**从时间区间与工具产出里推断**出来的，因此：

- 带 `?` 角标的子卡片 = **时序推断**，可能不准
- 不带角标 = 在该父调用的产出里找到了子调用的 id，证据更强
- 会话头部的 `Sub-agents` 开关可以**一键切回完全扁平的列表**

推断有护栏（宁可漏连不可错连）：等跨度不连、并列不连、深度上限 3。

## ⚠️ 多会话带来的行为变化

这是本版本最需要留意的变化——**"连接 agent"不再断开其他 agent**：

- 连 Claude Code 后再连 Gemini CLI，**Claude Code 保持连接**（会话继续存活），只是聊天面板切换显示对象
- `ACP (Custom): New Conversation` 现在是**开一个新标签**，不再销毁当前会话
- 因此相关确认弹窗的文案已改为「当前会话保留在它的标签中」（原文案说会清空历史，与实现不符）
- 断开某个 agent 会关闭它的**全部**会话；关闭单个会话用标签上的 `×`

## ⚠️ 与上游并存的注意事项

本扩展**可以与上游 `formulahendry.acp-client` 同时安装**——这正是改命名空间的目的。

设置项键名不同（沿用我们自己的命名空间）：

| 上游 | 本扩展 |
|---|---|
| `acp.agents` | `acpc.agents` |
| `acp.autoApprovePermissions` | `acpc.autoApprovePermissions` |
| `acp.defaultWorkingDirectory` | `acpc.defaultWorkingDirectory` |
| `acp.logTraffic` | `acpc.logTraffic` |

**如果你从上游迁移过来**，需要把 settings.json 里的 `acp.*` 改成 `acpc.*`，否则 agent 列表会是空的。

命令面板里本扩展的命令统一带 `ACP (Custom): ` 前缀，与上游的 `ACP: ` 区分。

## 已知问题

**新面板（Claude Code）**

- **子 agent 分组是推断的**（见上）。没有实测过 Claude Code 的 `rawInput`/`_meta` 里有没有显式父子键——
  如果将来发现适配器其实提供了显式链接，时序启发式会被替换掉。
- 切换 agent 时聊天面板会整体重渲染；新面板的记录存在扩展侧所以内容不丢，但滚动位置会重置。

**旧面板（其他 agent，继承自上游，本版本未修）**

- **文件附件仍不可用**——旧面板的 webview 没有消费 `file-attached` 消息的代码。
  这是刻意保留的：不在上游文件里修旧缺陷，避免制造合并冲突。要附件请用 Claude Code + 新面板。
- **Escape 取消失效**——`acpc.turnInProgress` 上下文键在上游代码里从未被 `setContext`，
  相关 `when` 条件恒为 false。可用命令面板的 `ACP (Custom): Cancel Current Turn` 替代。
- 工具调用不显示任何详情（无 diff / 无终端输出 / 无文件跳转）。

**通用**

- agent 需自行安装并位于 `PATH` 或可通过 `npx` 获取，本扩展不负责安装。
- 新面板的界面**尚未经过完整的人工验收**——自动化检查（类型 / lint / 构建 / 28 条测试 / 自检）全绿，
  但手动点击验收只跑了一部分。遇到问题请反馈。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.2.vsix`，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.2.vsix
```

或在 VS Code 中：扩展面板 → `...` 菜单 → **Install from VSIX...**
