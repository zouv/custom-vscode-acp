# v0.2.0-custom.7

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动

> 本版本覆盖 `CUSTOM-20261002-173` … `CUSTOM-20261004-181`（custom.6 之后的全部轮次）。

### 诊断能力：构建指纹与日志桥（173）

- `20261002-173`：日志首行与 webview 文档都带上**构建指纹**（`v版本·git短sha·打包时间·bundle sha256前12位`），
  客户端 boot 也会把自己拿到的那个值报出来 —— "这个窗口跑的是哪份代码"从此可以直接读，不必再靠推理。
  同时把客户端日志桥从"每次加载共 50 条"的**终身**上限改成**滚动窗口**（10s/30 条）：
  实测旧上限会被 markdown 诊断的噪声在 200ms 内烧光，此后任何诊断都进不了日志（pitfalls #42）。

### 表单（AskUserQuestion）选项说明丢失 —— 根治（174/175）

- `20261003-174`：单选回归**原生 radio 交互**（再点已选中行不再取消选择；清除只走底部的 `Clear answer`）。
- `20261003-175`：**`@agentclientprotocol/sdk` 0.21.1 → 1.7.0**。旧版 SDK 用 zod 校验入站请求，
  而它的选项 schema（`zEnumOption`）只声明 `const`/`title` —— zod 会**丢弃未声明的键**，
  于是 adapter 明明发来的 `description`（选项说明）与 `_meta`（含 `preview`）在进入本扩展之前就没了。
  1.3.0 起上游已补上这两个字段。迁移点三处：客户端方法改名（`unstable_createElicitation` → `createElicitation`）、
  `Stream` 改从主入口导入、models API 消失（模型改走 Config Options；旧 API 兜底加存在性判断）。
- `20261004-176`：底部浮层（输入卡 / 表单抽屉 / 权限抽屉）长高或收起后，**视口判定跟着重算** ——
  贴底者的视口随留白走、最后一条不再被浮层盖住却滚不动，`Jump to latest` 也不会再挂着不消失。

### 界面细节

- `20261004-177`：表单抽屉**收起后保留完整 tab 条**（每一题的标题与已答/未答圆点都在，点任一 tab 会展开到那一题）。
- `20261004-178`：点置顶卡跳回原处后，看到的是**真实消息**（正常样式）—— 落点越过判定线一点点，
  上方卡堆按既有公式自己滑出上沿（此前"就地接管"会让人一直看悬浮样式）。
- `20261004-179`：置顶卡与消息记录的**折叠状态双向同步**（点卡片三角 = 消息也折，反之亦然），
  且重建/切会话回来仍然记得（此前记录侧写死展开）。
- `20261004-180`：长会话里折叠一次不再卡 —— `rail.measure()` 从"边读边写"（每个标记一次强制重排）
  改成读写分离；置顶条的用户消息列表按内容版本缓存。
- `20261004-181`：置顶卡堆**留 8px 缝**（卡与卡、卡与它顶住的那条之间），不再严丝合缝粘成一条。

> 顺带修好 `CUSTOMIZATIONS/scripts/preview-records.mjs` 的探针自检：它原先定位到的是自己那行代码里的
> 字面量，一直在校验一段空区域（写进反引号也照样报 OK）—— 见 pitfalls #45。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.7.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.7.vsix
```
