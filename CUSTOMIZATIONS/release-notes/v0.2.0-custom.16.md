# v0.2.0-custom.16

发布日期：2026-11-01。基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659e3ac100db842b419b1361205a193032e）。

## 本版本自定义改动

本版本包含 CUSTOM-20261101-001～015 的修复，发布登记为 CUSTOM-20261101-016。

- **文件数据保护**：读取未保存编辑器缓冲区；拒绝覆盖 dirty 文档；用 realpath 识别 Windows 大小写、符号链接别名；clean 文档写入同步编辑器与磁盘。
- **进程与工具终端**：修复 Windows native/cmd 参数转义、UTF-8 分块与字节限制、即时输出、会话所有权及进程树清理。
- **连接与多会话**：握手失败和断开清理；共享 Agent 的会话错误隔离；全页会话列表去重、游标防护与非权威联合历史保护；退出前尽力 flush 恢复快照。
- **ACP 接线**：实现 terminal auth 的交互终端执行与取消生命周期；正确合并认证 argv/env；configOptions（含空数组）优先；不支持的模型操作及 prompt block 明确拒绝；Claude/Codex 统一使用多会话界面。
- **隐私与稳定性**：协议原文和持久日志默认关闭；窗口隔离、限额队列与持续日志轮转；夹具、预览及测试中的身份/机器路径使用占位值，并新增夹具隐私闸门。
- **构建与分发**：独立 webpack 测试 bundle 兼容 ESM SDK 和最低宿主，保留预览所需 out 模块；修复 Registry v1 schema、并发缓存和超时；只分发生产 runtime bundle，不带源码、测试、source map、声明及开发文档；CI 补 Node 22、最低宿主与包内容门禁。

## ACP 尚未覆盖的能力

检查以 Claude 适配器0.99.1、Codex 适配器0.16.0、本地 ACP SDK1.7.0 为固定版本边界，详见 CUSTOMIZATIONS/docs/acp-compatibility.md：

- 用户自定义 MCP 配置尚未贯通 session/new、load、resume；Agent 自身 MCP 配置不受此结论否定。
- Codex EnvVar/API Key 认证仅覆盖启动前配置环境，未实现安全输入、SecretStorage 和共享 Agent 无损重连。
- Claude fork/delete、provider/systemPrompt，以及两者 logout 等入口尚未接齐；本地归档不等于远端删除。
- customModels 的 _meta.extraModels 是配套 Claude fork 的私有扩展，不能宣称 stock Claude/Codex 通用支持。

历史 changelog 的两处私人路径及既有 Git 身份历史未改写，后续清理需要明确授权；本轮脱敏与闸门不等于完整历史、秘密或二进制审计。

## 与上游并存

命令/配置前缀为 acpc.*（上游为 acp.*），扩展 id 为 zouv.acp-client-custom，可与 formulahendry.acp-client 同时安装、独立配置。本版本只发布到 zouv/custom-vscode-acp 的 GitHub Release，不发布 Marketplace / Open VSX。

## 安装

下载 Release 附件 zouv.acp-client-custom-0.2.0-custom.16.vsix，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.16.vsix
```
