# v0.2.0-custom.13

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动（2026-10-10 · CUSTOM-20261010-230 / 231 / 232）

- **230　触底自愈门槛放宽**：修「滚动条到底了、底部没显示完，Jump 能恢复、滚轮又坏」——自愈的 at-max 门槛原来是 `max−1`（1px 容差），滚轮滚到底常落在 `max−N` 而非精确 `max`，自愈不触发、尾巴一直压在输入卡后面；放宽到 `max−PIN_THRESHOLD`（32px）。
- **231/232　多根工作区（显式选择 UI）**：
  - 输入栏左下角新增一个 **`+`** 按钮 → 弹出一级菜单：
    - 📁 **Workspace directories** → 二级菜单（返回 + 工作区根目录多选 + Browse 自定义目录）。选中的目录会作为 `additionalDirectories` 随 `session/new` 下发，让 agent 一次激活多个根目录、读到各目录的 AGENTS.md / skills。已选目录以 chip 显示在输入框上方、可摘除；已有会话里该项**灰置**（additionalDirectories 创建后锁死不可改），但已选的目录仍只读展示。
    - 📄 **Files or folders** → 打开文件选择器（多选文件），选中的文件作为引用加进消息（与「编辑器当前文件」chip 同一条附件通道）。
  - 两个菜单项各带图标（folder / document）。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.13.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.13.vsix
```
