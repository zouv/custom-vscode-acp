# v0.2.0-custom.5

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动

### 连接与初始界面

- `20260930-123..125`：**连接状态卡**（未连接 / 连接中 / 已就绪三态）+ 配置项 `acpc.autoConnectOnOpen`（默认开：面板打开 0.5s 后自动连接；同一张卡片上可勾选，两边双向同步）
- `20260930-126..131`：记录时刻挂到标题行、底部上下文用量改**圆环**、标签栏状态点（颜色 = 状态，外圈 = 正在做事）、未连接时隐藏 header 上的 Times

### 底部输入区

- `20260930-132..139`：消息列与输入区加版心 → 按要求撤销消息区限宽、输入卡改**一体式悬浮卡片**（默认一行高，多行时才长高）
- `20260930-138`：右下角**预留功能区** —— 竖线与大纲栏同宽（对着同一条线）；没有大纲（未钉住）时它自动隐藏、输入卡居中
- `20260930-140..143`：**真悬浮**（消息一路铺到面板底、只有滚动到底那一刻才给输入卡让位）、未连接时整块隐藏底栏
- 修掉两个**只在编辑区面板**里才暴露的坑：`.surface-editor .composer` 的不透明背景会把浮层变成一条实心带（挡住两侧消息与大纲栏底部）；底栏通栏之后空区会吞掉大纲栏底部的点击

### 目录过滤与时刻

- `20260930-141`：历史浮层的目录过滤菜单不再被外层滚动容器裁剪（滚动下移到列表），并加高亮边框与历史列表区分
- `20260930-142`：目录候选改按**名称字母序**
- `20260930-145..146`：Times 的**时刻只显示在工具卡上** —— 只有工具调用才有耗时（`elapsedMs`），其余记录本来就没有这个量

### 修复

- `20260930-147..149`：**最后一条助手消息不渲染 markdown**。客户端 `transcriptView.sessionId` 在 `reset()`（重开面板 / 切会话）之后为 `null`，markdown 回填因此被宿主 `verifySession` **静默丢弃**；改为由每条带记录的消息自带的 `sessionId` 校正它。
- `20260930-150`：把"日志落盘"这条排查路径放回**入口处**（`docs/dev-workflow.md` 新增「排查入口」一节 + `pitfalls` #35）。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.5.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.5.vsix
```

## 排查

出问题时日志**已经自动落盘**，不必手动拷贝输出面板：

```
~/.claude/acp-client-custom.log        # Windows: %USERPROFILE%\.claude\acp-client-custom.log
```

宿主与 webview 客户端的日志都在里面（客户端的前缀是 `chat-panel: client(warn):`）。
