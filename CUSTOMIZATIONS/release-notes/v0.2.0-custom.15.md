# v0.2.0-custom.15

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动（2026-10-13 · CUSTOM-20261013-237）

- **237　修「目录筛选的下拉列表被会话列表盖住」**：点会话历史的 ↺ 打开历史列表后，再点标题栏上的
  目录筛选 chip，弹出的下拉菜单会被列表行的文字压住 —— 两层互相透底，`N sessions` 那几行几乎读不出来
  （用长标题的会话尤其明显）。

  现在菜单稳定浮在列表之上，列表行文字在菜单左缘被截断，点选不再落到底下的会话行上。

  根因是几天前（`CUSTOM-20261009-212` 给历史行加悬停的 Archive / Rename 图标）引入的**层叠退化**：
  行被套上 `position: relative` 之后，每一行都成了「定位元素、`z-index: auto`」，与同样是 `auto`
  的浮层头部落在同一个绘制步里，按 DOM 顺序画 ⇒ 列表排在后面就画在了菜单之上。修复只是把浮层
  头部抬一格（`z-index: 2`），菜单整棵子树随之浮到所有行之上。

  > 顺带修好了同一处的另一个隐性问题：列表向上滚动时，粘性头部本该盖住滚过去的行。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.15.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.15.vsix
```
