# v0.2.0-custom.1

基于上游 [formulahendry/vscode-acp](https://github.com/formulahendry/vscode-acp) `0.2.0`（commit `e7371659`）的首个自定义版本。

## 这个版本做了什么

本版本是 **fork 的初始配置版**——功能与上游 `0.2.0` 一致，改动集中在扩展身份、命名空间与仓库机制上。

| change-id | 内容 |
|---|---|
| CUSTOM-20260923-001 | 扩展身份改为 `zouv.acp-client-custom`；全局命名空间 `acp.*` → `acpc.*`（21 个命令 id、视图/容器 id、4 个配置项、上下文键、输出通道名、命令标题） |
| CUSTOM-20260923-002 | **移除遥测**——上游硬编码了作者自己的 Application Insights 连接串并向其上报使用数据 |
| CUSTOM-20260923-003 | 打包与忽略卫生：开发机制目录与 `.github/` 不进 `.vsix` |
| CUSTOM-20260923-004 | `publish.yml` 改为只打包并上传 Release 资产，不发布插件市场 |
| CUSTOM-20260923-005 | 固定换行符处理（`.gitattributes`），防止整文件伪差异破坏后续上游合并 |

## ⚠️ 与上游并存的注意事项

本扩展**可以与上游 `formulahendry.acp-client` 同时安装**——这正是改命名空间的目的。但请留意：

**设置项键名不同**（沿用我们自己的命名空间）：

| 上游 | 本扩展 |
|---|---|
| `acp.agents` | `acpc.agents` |
| `acp.autoApprovePermissions` | `acpc.autoApprovePermissions` |
| `acp.defaultWorkingDirectory` | `acpc.defaultWorkingDirectory` |
| `acp.logTraffic` | `acpc.logTraffic` |

**如果你从上游迁移过来**，需要把 settings.json 里的 `acp.*` 改成 `acpc.*`，否则 agent 列表会是空的。两个扩展各自独立配置、独立运行。

命令面板里本扩展的命令统一带 `ACP (Custom): ` 前缀，与上游的 `ACP: ` 区分。

## 已知问题

以下问题**继承自上游**，本版本未修：

- **文件附件不可用**：`ACP (Custom): Attach File to Prompt` 会弹出文件选择框，但附件不会被送进对话。（webview 侧没有处理 `file-attached` 消息的代码）
- **Escape 取消失效**：`acpc.turnInProgress` 上下文键在上游代码里从未被设置，导致 Escape 快捷键与取消按钮的 `when` 条件恒为 false。可用命令面板的 `ACP (Custom): Cancel Current Turn` 替代。
- agent 需自行安装并位于 `PATH` 或可通过 `npx` 获取，本扩展不负责安装。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.1.vsix`，然后：

```bash
code --install-extension zouv.acp-client-custom-0.2.0-custom.1.vsix
```

或在 VS Code 中：扩展面板 → `...` 菜单 → **Install from VSIX...**
