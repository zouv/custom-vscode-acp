# v0.2.0-custom.6

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动

> 本版本覆盖 `CUSTOM-20260930-151` … `CUSTOM-20261002-172`（custom.5 之后的全部轮次）。

### 置顶卡：从「只钉一条」改成整段前缀（卡堆式推挤 + 抽回）

- `20261002-172`：悬浮置顶卡不再只钉住最近一条提问 —— 顶边越过判定线的**每一条**用户消息各得一张卡，
  新提问的顶边碰到旧卡底边时两张一起悬浮（上旧下新、严丝合缝），继续滚旧卡被逐渐**顶出上沿**直到看不见，
  反向滚动又从上沿**原路抽回**（与浏览器原生 `position: sticky` 的分区头语义一致）。
  顺带修掉"消息新增后不重排"的缺口（流式内容改变高度时旧卡会发飘）。
- `20261002-169/170/171`：卡里的折叠三角才是收缩控件（左侧那个小方块已删除）；折叠改走**原生 `<details>`**
  （与界面里的折叠同一套逻辑）；点卡片跳回原处时消息**就地接管卡片的位置**（不再被卡片盖住、也不再被挤到下面）。

### 表单（AskUserQuestion）：从消息卡片改成悬浮抽屉

- `20260930-152`：agent 提问不再在记录流里铺开一张表单卡 —— 记录里只留一行「⏳ 待回答 · 题干摘要 + Open form」，
  表单本体进**悬浮抽屉**（贴在输入卡上方、与它同宽同中线；多道题按 tab 分页；可收起成一行；消息区按它的高度让位）。
  宿主侧零改动：记录仍是唯一真相，切会话 / 双 surface / 重挂载都靠快照带回。
- `20261001-153`：复验四条 —— 抽屉的居中**与输入卡同源**（钉住大纲栏时不再偏 120px）、
  只显示**属于当前会话**的表单、自拟框与问题的配对兜底（adapter 新版不再发 `_meta` 标记）、
  下拉菜单一律开在按钮下方。
- `20261001-154`：第二轮复验四条 —— **单选改平铺列表**（每行 = 主标题 + 副标题，末尾一行 `Other`，
  并给一个 `Clear answer` 守住"允许不选"）、**自拟框跟着被选中的那一行**（默认不显示，选了才出现）、
  去掉标题行（tab 条 + `Answered n/N` + 收起箭头合成一条 bar，进度靠右）、
  切到草稿页 / 别的会话时浮框不再残留（所有"清记录"的路径统一对账抽屉）。
- `20261001-161/168`：多题表单的 `Submit` **只在最后一题那一页可点**（防误提交）；附加说明改**追加**语义、
  说明行移进 tooltip、单选可取消选择、多选每项带自己的补充框。

### 权限请求：也改成悬浮抽屉

- `20261001-158`：权限的作答界面从记录区内联卡片改成**输入框上方的悬浮抽屉**（与表单抽屉同形）。

### 后台会话的请求：改成右下角通知

- `20261001-156/157`：后台会话的权限 / 表单请求改发**右下角通知**（点击跳转聚焦），不再弹窗口顶部的 QuickPick；
  "轮次完成"也走同一套通知。
- `20261001-162`：轮次结束后**后台子任务还在跑**时，发送按钮不再变回普通状态（认 `run_in_background` + 看门狗）。

### 草稿页（点「+」的新会话页）：输入卡补全

- `20260930-151`：草稿还没有会话，而模式 / 模型 / 斜杠命令在 ACP 里都是**会话级**的（`session/new`
  根本没有 mode/model 入参）—— 现在宿主按 agent 存一份"上一次会话的快照"，草稿页据此渲染完整输入卡；
  你在草稿页选的值随首条消息一起走，会话建出来之后逐项校验、**在第一轮之前**应用。
  快照跨窗口重载持久化（`globalState`），所以全新窗口点「+」也是完整的。
- `20261001-159/160`：记住用户**手动选过**的模式，**新建**会话时默认套用（打开历史会话不套用）；草稿页显示它。

### 会话列表与标题

- `20261001-155`：历史会话按钮（↺）的默认筛选改为**跟随地址栏**的目录。
- `20261001-163/164`：会话进行中不再冒出「Session renamed to …」那一行；标题改为**由第一次对话定死**
  （不再在"聊了几轮之后才生成"的自动命名上改名）。
- `20261001-165`：新建会话（草稿页）时输入框的上下文表盘、附件 chip、图片浮层都不再残留上一个会话的状态。

### 置顶卡的判据与收缩（166-167）

- `20261001-166/167`：判据按用户要求再改（上方还有提问就钉住最后那条滚出上沿的）；收缩按钮做成看得见的控件、
  折叠状态按会话记；点卡片里的折叠三角不再触发跳转；置顶条离顶栏 8px → **3px**。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.6.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.6.vsix
```
