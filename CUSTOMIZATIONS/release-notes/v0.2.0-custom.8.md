# v0.2.0-custom.8

基于上游 formulahendry/vscode-acp 0.2.0（commit e7371659）

## 本版本自定义改动

> 本版本覆盖 `CUSTOM-20261004-182` … `CUSTOM-20261005-192`（custom.7 之后的全部轮次）。

### 输入与轮次

- `20261004-182`：**回车只发送，绝不停止**。此前回车与 Send/Stop 按钮共用一条路由，发完消息手还在键盘上时第二次回车会把**整轮**停掉（工具调用被掐断，不可逆）。
- `20261004-183`：**停止要二次确认**。Escape 与 Stop 按钮都不再直接中止，先在输入卡上方问一句；`Keep going`（或再按一次 Escape）收起。只有"停止"加这一步 —— 关菜单/浮层/表单抽屉都能重开，不打扰。
- `20261004-187`：**任务进行中也能补发消息**（Claude Code 的 `_session/steering`）—— 把消息**注入正在跑的那一轮**，而不是排成第二个轮次；不支持的 agent 保持不发，但会在输入卡上方写明原因（此前是静默无反应）。

### 渲染

- `20261004-184`：**正文里的本地文件链接可以点了**。`[GOAL.md:74](GOAL.md:74)` 这类此前被当成"不认识的协议"渲染成灰色删除线、点了没反应；现在接上内容块早就有的 `openFile` 通道（按会话 cwd 解析相对路径 + 跳行号）。
- `20261004-186`：**修"消息显示不全"** —— 长回复只显示开头几个字、后面一个字都没有。根因是渲染回填带的是**请求发出那一刻**的文本，而正文一直在流；现在一份 html 只对"它照之渲染的那段文本"有效，回填对不上就丢弃，收尾时按当前文本重要一次。
- `20261005-191`：**大纲栏两类行拉开区分度**（用户 = 骨架：亮色 + 加粗；助手 = 补充：暗色 + 略小 + 图标半隐）。

### 上下文圆环

- `20261004-185`：**修"超过上限"**（`100% · 1841k / 1000k`）。此前把 `PromptResponse.usage.totalTokens`（整段会话的**累计**量）折进了"当前上下文占用"，长会话必然越界；现在圆环只认 `usage_update`。顺带金额只保留两位小数。
- `20261004-190`：**修"任务进行中外圈不转"**。外圈那条动画靠节点活着，而每次 `sessionsChanged` 都会重建表盘（宿主每个 chunk 都发一次）⇒ 动画永远停在起点。现在数字没变就只改类名，不重建。

### 表单与焦点

- `20261004-188`：**修"弹出选项面板时默认聚焦到最后一个 tab"** —— 页号改成按表单记，新表单从第一页开始。
- `20261004-189`：**修"输入一个字符就失去焦点"** —— 自拟框以前每一次 refresh 都会被 `appendChild` 搬一次（等于先摘再插），现在只在真的换行时才搬。

### 诊断能力

- `20261005-192`：**滚动链路全覆盖自检日志**。用户报"消息面板还没移到底部，滚动条就已经触底了"（176 修过同类，但预览档里那条链是自洽的 ⇒ 还有另一条路）。与其猜，不如把账打出来：`pinned` 翻转、`user-scroll` vs `scroll-after-program`、`grew-unpinned`、`clamped-short`、以及三个底部留白变量（输入卡/表单抽屉/权限抽屉）的**变化点**各记一行，带序号、节流与自带配额（不烧日志桥的共享额度）。下次复现时 `grep "acpc] scroll#"` 即可定案。

## 与上游并存的说明

本扩展的命令前缀为 `acpc.*`（上游为 `acp.*`），扩展 id 为 `zouv.acp-client-custom`，
可与上游 `formulahendry.acp-client` 同时安装、独立配置。

## 安装

下载下方的 `zouv.acp-client-custom-0.2.0-custom.8.vsix`，然后：

```
code --install-extension zouv.acp-client-custom-0.2.0-custom.8.vsix
```
